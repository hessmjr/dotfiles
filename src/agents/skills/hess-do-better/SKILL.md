---
name: hess-do-better
description: Ask for a review of whether a code path can be improved.
---
Can you dig into the specified code and determine if there is a better approach?

- Is there a simpler approach that achieves the same result
- Is there an approach that could solve more with the same code impact
- Can this approach be re-worked into less code changes (not at the expense of ease of understanding/readability)
- Is similar logic repeated in ways that could be pulled into one place (DRY)
- Or any other way you feel it could be better
